# Available labeled dataset

word_labels.csv combines the four existing Examples_label files. Each row contains a word or text unit, its video ID, timestamps, and original O/B/I/L/U label. Source labels are preserved without reinterpretation. Language and region are joined from the supplied metadata where available.

This is a partial dataset, not labels for all 3,617 videos. No video downloads or audio processing were started. The eight-second verification clip is excluded.
